# Pupier et al, 2026. BioniKK ccRCC BCR repertoire analysis in relation to TLS and ICI-treatment response

This repository contains the scripts used for the analyses presented in:

> Pupier et al, TLS-associated B cell repertoire shaping and response to immune checkpoint inhibitors in patients with renal cell cancer ; under revision (2026-09)

## Code corresponding to the initial manuscript submission

Version: v1.0.0

## Contents

The `scripts/` directory contains the 6 R scripts (R Markdown) and 1 python script used for the analyses presented in the manuscript.

## Data availability

The raw sequencing data are available through the European Genome-phenome Archive (EGA) under controlled access.

## Reproducibility

The scripts were used to generate the preprocessing of raw data, all analyses and all igures presented in the manuscript.
